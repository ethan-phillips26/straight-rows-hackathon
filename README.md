# Straight Rows

Individual entry, Bluestaq × NDSU Straight Rows Hackathon: detecting degraded GNSS guidance on a simulated 3-tractor fleet.

Work in progress.

## Setup
```bash
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Tests
```bash
pytest -q
```
